# B ♥ S Wedding

การ์ดเชิญงานแต่งงานออนไลน์ของ **บงกช & ศุภกร**
วันเสาร์ที่ 13 กุมภาพันธ์ 2570 ณ ไฮครีก รีสอร์ท แอนด์ แค้มป์ไซต์ อ.ศรีบุญเรือง จ.หนองบัวลำภู

เว็บ: https://namchiaw100.github.io/bs-wedding/

## ในการ์ดมีอะไร

- หน้าแรกเป็นภาพคู่พร้อมเครื่องเล่นเพลง (เพลงรัก – Three Man Down)
- นับถอยหลังถึง 09.09 น. วันที่ 13 ก.พ. 2570 และปุ่มบันทึกลง Google Calendar
- คำเชิญจากครอบครัวทั้งสองฝ่าย ชื่อบ่าวสาว กำหนดการ
- แผนที่ Google Maps และปุ่มนำทาง
- ธีมสีการแต่งกาย, แกลเลอรีภาพ
- แบบตอบรับการเข้าร่วมงาน และผนังคำอวยพร

## ไฟล์

| ไฟล์ / โฟลเดอร์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าการ์ดทั้งหมด (ไฟล์เดียว) |
| `images/` | ภาพที่ใช้ในการ์ด |
| `music/` | วางไฟล์เพลง `love-song.mp3` ที่นี่ ดู `music/README.md` |
| `rsvp/` | โค้ด Google Apps Script สำหรับเก็บคำตอบลง Google Sheet ดู `rsvp/README.md` |
| `.github/workflows/pages.yml` | อัปเดตเว็บอัตโนมัติทุกครั้งที่ push เข้า `main` |

## เปิดเว็บครั้งแรก

ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions** (ทำครั้งเดียว)
จากนั้นทุกครั้งที่แก้ไฟล์และ push เข้า `main` เว็บจะอัปเดตเองภายในราว 1 นาที

## ทดลองในเครื่อง

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```
