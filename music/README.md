# เพลงประกอบการ์ด

วางไฟล์เพลง "เพลงรัก – Three Man Down" ไว้ที่โฟลเดอร์นี้ ตั้งชื่อว่า `love-song.mp3`

- เพลงจะเริ่มเล่นทันทีเมื่อแขกกดปุ่ม "เปิดการ์ดเชิญ" (เบราว์เซอร์ไม่อนุญาตให้เปิดเสียงเองก่อนผู้ใช้แตะหน้าจอ)
- มีปุ่มเปิด/ปิดเพลงลอยอยู่มุมขวาล่าง
- ถ้ายังไม่มีไฟล์นี้ ปุ่มเพลงจะซ่อนไว้ หน้าการ์ดยังใช้งานได้ตามปกติ
- แนะนำขนาดไฟล์ไม่เกิน ~5 MB (MP3 128 kbps)
