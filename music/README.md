# เพลงประกอบการ์ด

`song.mp3` คือเพลง "ดาวหางฮัลเลย์ – fellow fellow" ตัดตั้งแต่ 0:30 จนจบเพลง (เฟดเข้า 1.5 วินาที ท้ายเพลงเฟดออกตามต้นฉบับ) MP3 128 kbps

- เพลงเริ่มเล่นเมื่อแขกกดปุ่ม ▶ ที่หน้าแรก (เบราว์เซอร์ไม่อนุญาตให้เปิดเสียงเองก่อนผู้ใช้แตะหน้าจอ)
- เล่นวนซ้ำอัตโนมัติ ปิด/เปิดได้จากปุ่มโน้ตเพลงลอยมุมขวาล่าง
- ถ้าจะเปลี่ยนเพลง: แทนที่ไฟล์ `song.mp3` (แนะนำไม่เกิน ~5 MB) แล้วแก้ชื่อเพลงใน `index.html` ตรง `class="song-meta"`
- ถ้าไม่มีไฟล์นี้ เครื่องเล่นจะขึ้นข้อความ "เพลงกำลังจะมาเร็ว ๆ นี้" และหน้าการ์ดยังใช้งานได้ปกติ
