# เก็บคำตอบ RSVP และคำอวยพรลง Google Sheet

ถ้ายังไม่ได้ตั้งค่า หน้าการ์ดจะเก็บคำตอบไว้ในเครื่องของแขกแต่ละคนเท่านั้น (บ่าวสาวจะมองไม่เห็น)
ทำตามขั้นตอนนี้ครั้งเดียว ใช้เวลาประมาณ 5 นาที

1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น `B♥S Wedding RSVP`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ `apps-script.gs` กด **บันทึก**
4. กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. กดอนุญาตสิทธิ์ แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
6. เปิด `index.html` หาบรรทัด `var RSVP_ENDPOINT = '';` แล้ววาง URL ไว้ในเครื่องหมาย `''`

หลังจากนั้น
- ทุกคำตอบจะเข้าแท็บ `RSVP` ใน Google Sheet (ชื่อ, มา/ไม่มา, ฝ่าย, จำนวนคน, อาหารที่ทานไม่ได้, คำอวยพร)
- คำอวยพรของทุกคนจะแสดงบนหน้าการ์ด ส่วนข้อมูลอาหารจะไม่แสดงต่อสาธารณะ
- ถ้ามีข้อความไม่เหมาะสม ลบแถวนั้นออกจาก Sheet ได้เลย หน้าการ์ดจะไม่แสดงอีก
